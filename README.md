# 數學遊戲樂園

直接用瀏覽器開啟 `index.html`，不需安裝依賴。請保留 `games/` 與入口網頁的相對位置。遊戲在新分頁開啟，原入口保留。

- 01：低年級（1–2 年級），4 個遊戲
- 02：中年級（3–4 年級），3 個遊戲
- 03：高年級（5–6 年級），2 個遊戲

也可在此目錄執行 `python3 -m http.server 8000`，或將整個目錄部署至靜態網站服務。

遊戲維持獨立 HTML 檔案；功能更新與遊戲版本記錄於 [CHANGELOG.md](CHANGELOG.md)。

後續遊戲更新需在遊戲畫面標示版本，功能更新調整次版本，錯誤修正調整修訂版本。需先檢閱的更新使用 preview 版本，確認後才正式發布。
